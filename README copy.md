# To-Do List (Flask + SQLite)

    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

- Add, edit (click title), complete, delete tasks; priority + due date; overdue highlight
- Filters (All/Active/Done), search, progress bar, clear completed
- SQLite `tasks` table via REST API (GET/POST/PATCH/DELETE)
- Responsive layout, light print-friendly theme
